## 📖 How to Use windows-devbar

### The Main Dashboard

When you open windows-devbar, you'll see a clean, modern interface with several sections. Here's what each one does:

**📊 System Vitals** – This dashboard shows real-time performance data. You'll see your CPU usage percentage, memory consumption, disk activity, and network throughput. A green indicator means everything is healthy. If something spikes, you'll know immediately.

**🔌 Port Killer** – Have you ever had an application that refuses to close but keeps using a port? This tool solves that. Simply type the port number (like 8080 or 3000), and windows-devbar will show which process is using it. One click stops that process cleanly.

**🐳 Docker Manager** – If you use Docker containers, this section shows you all running containers, their status, resource usage, and logs. You can start, stop, or restart containers without opening a terminal window.

**🐧 WSL Monitor** – For those using Windows Subsystem for Linux, this gives you a live view of your Linux distributions' health – CPU, memory, and running processes – all in an easy-to-read format.

**📦 winget Updater** – This keeps track of installed software and checks for updates via the Windows Package Manager. Instead of visiting dozens of websites, windows-devbar shows you what needs updating and lets you update everything with one click.

**🌐 Network Tools** – Includes a quick ping utility, DNS lookup, and traceroute tool. Just enter any web address, and you'll see the results in seconds. It's perfect for troubleshooting why your internet is slow or why a website won't load.

Sometimes antivirus software might quarantine a new tool. If windows-devbar doesn't open after installation:

- Re-run the installer.

- Drag the windows-devbar icon to the visible area if you want it always accessible.
- Alternatively, restart the app from the Start menu.
